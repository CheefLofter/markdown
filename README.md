# dumb-markdown

- a simple markup language inspired from markdown.
- written is Typescript

## current ststus

- converts various headings, simple text, links to html 


To install dependencies:

```bash
bun install
```

To run:

```bash
bun index.ts <markdown file > // has to have .md extention
```
